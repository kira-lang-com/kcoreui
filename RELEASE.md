# 26.10.4

**Project:** KCoreUI  
**Release week:** 2026-10-26 – 2026-11-01

## Highlights

The first source release of KCoreUI includes:

- A writer and parser for compiled `.kcui` visual resource catalogs.
- Catalog stacking and environment-dependent resolution of semantic resources such as colors, materials, and typefaces.
- Byte-exact catalog round trips, including resources whose kinds are not decoded by the current build.
